# Трапчик.мп3 — Web MVP

Это адаптивное музыкальное веб-приложение на Next.js с Supabase Auth, каталогом релизов и публикацией музыки администраторами.

## Что уже работает в проекте
- Адаптивная главная страница для телефона и компьютера.
- Регистрация с никнеймом, email и паролем через Supabase Auth.
- Вход и выход.
- Вывод опубликованных альбомов из `public.albums`.
- Вывод опубликованных треков из `public.tracks`, аудиоплеер и клипы.
- Вывод анонсов из `public.upcoming_releases`.
- Проверка статуса профиля `blocked` после входа.
- Пункт «Админ-панель» в боковом меню для активных администраторов.
- Публикация треков и альбомов с загрузкой файлов в Supabase Storage.

## Что пока не подключено
- Синхронизированные тексты.
- Избранное, плейлисты, история.
- Комментарии и оценки в интерфейсе.
- Админ-панель.
- Публикация сайта в интернете и мобильные приложения.

Это MVP, для работы которого нужен настроенный Supabase и назначенная владельцем проекта роль администратора.

## Админ-панель и медиа

Войдите под активной учётной записью с `profiles.role = 'admin'`. Роль не назначается сайтом автоматически. Пункт «Админ-панель» появится в боковом меню. Отдельный маршрут `/admin` повторно проверяет роль, а операции публикации дополнительно ограничены политиками RLS таблиц и Storage.

Файлы сохраняются в существующий закрытый bucket `music-media` с уникальными ключами. Допустимы аудио MP3, M4A, AAC, WAV, OGG и FLAC; видео MP4, WebM и MOV; изображения JPG, PNG и WebP. Максимальный размер одного файла — 100 МБ. Публикуемые файлы могут читать активные пользователи, если они привязаны к опубликованному треку или альбому. Загрузка, изменение и удаление доступны только администраторам.

Исполнители указываются через запятую, точку с запятой или с новой строки; в текущей схеме список сохраняется в `artist_name` одной строкой. Треки первой версии публикуются отдельно от альбомов.

## 1. Что нужно установить
На компьютере с Windows установи:
- Node.js LTS: https://nodejs.org/
- Visual Studio Code: https://code.visualstudio.com/

Распакуй ZIP в отдельную папку и открой эту папку в VS Code.

## 2. Настрой Supabase
Проект уже создан и схема базы применена. Его URL:
`https://rtjxbcppcdwoznkobpdu.supabase.co`

Публичный Publishable key:
1. Открой Supabase Dashboard.
2. Выбери проект `sirnik1n2n3@gmail.com's Project`.
3. Нажми **Connect** или открой **Settings → API Keys**.
4. Скопируй **Publishable key** (начинается с `sb_publishable_`).

Создай в корне проекта файл `.env.local` (рядом с `package.json`) и вставь:

```env
NEXT_PUBLIC_SUPABASE_URL=https://rtjxbcppcdwoznkobpdu.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=ВСТАВЬ_СЮДА_PUBLISHABLE_KEY
```

Не отправляй ключи в чат. Publishable key предназначен для браузера, но секретный/service_role key сюда вставлять нельзя ни при каких обстоятельствах.

## 3. Включи подтверждение email
В Supabase Dashboard:
1. Authentication → Providers → Email.
2. Убедись, что Email provider включён.
3. Включи подтверждение email (Confirm email).
4. Authentication → URL Configuration: добавь адрес сайта в Site URL и Redirect URLs.
   Для локального теста добавь `http://localhost:3000/**`.
5. Для реального запуска позже заменим localhost на домен сайта.

Если письмо не приходит, проверь SMTP/email настройки Supabase и папку «Спам».

## 4. Запуск
Открой терминал VS Code (Terminal → New Terminal) и выполни:

```bash
npm install
npm run dev
```

Затем открой в браузере:
`http://localhost:3000`

## 5. Первая регистрация и назначение администратора
Зарегистрируйся на сайте и подтверди email. После этого в Supabase Dashboard:
- Authentication → Users → найди свой аккаунт и скопируй UUID.
- Открой SQL Editor и выполни запрос, подставив свой UUID:

```sql
update public.profiles
set role = 'admin'
where id = 'ВСТАВЬ_UUID_СВОЕГО_АККАУНТА';
```

UUID и роль не нужно менять через интерфейс сайта. Никогда не делай публичную регистрацию администратором.

## 6. Проверка сборки
После установки зависимостей:

```bash
npm run build
```

Пакеты зафиксированы в `package.json`. Если npm сообщает, что версия пакета недоступна, пришли точный текст ошибки — подберём совместимые версии.

## Важно
Публичные `NEXT_PUBLIC_` переменные видны браузеру. Это нормально только для Supabase URL и Publishable key при корректно настроенном RLS. Не добавляй сюда `service_role`, secret key, пароль базы данных или секреты Cloudflare.
