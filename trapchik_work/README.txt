Трапчик.мп3 — облегчённая CrystalizedBall

Распакуйте поверх папки проекта, заменив файлы. Затем в терминале VS Code из папки проекта выполните:
  npm.cmd install
  npm.cmd run cf:deploy

Пыль теперь испускается постоянно, пока играет музыка; одновременно на экране не больше 360 летящих частиц, отрисовка пакетная и ограничена 30 кадрами/с. После остановки музыки новые частицы не появляются, оставшиеся плавно исчезают, сфера становится серой. Встроенные 13 500 частиц CrystalizedBall сохранены. Тяжёлая реакция на клик сферы ограничена по времени и частоте кадров.

Если npm сообщит о неразрешённых install-скриптах esbuild/workerd, используйте команды в README из предыдущей версии архива: approve esbuild, approve workerd, затем npm.cmd rebuild.

Проверка: npm.cmd run build прошла успешно. Команда cf:deploy собирает проект и публикует его на Cloudflare.
