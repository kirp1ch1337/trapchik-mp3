# Сообщество Трапчик.МР3 — установка

В проект добавлена вкладка «Сообщество» в существующее боковое меню. Внутри неё есть поиск пользователей, взаимные подписки как список друзей, общий чат, личные диалоги и раздел стикеров. Администратор может создавать наборы, добавлять стикеры по HTTPS-ссылке и публиковать/скрывать наборы.

## Обязательный шаг: база Supabase

Перед публикацией открой Supabase → SQL Editor → New query, скопируй содержимое файла:

`supabase/migrations/20261110190000_add_community.sql`

и выполни его в проекте Supabase.

Миграция создаёт таблицы сообщений и стикеров, включает RLS и добавляет таблицу сообщений в Realtime. Она использует уже существующие `profiles`, `user_follows` и `public.is_admin()`.

## Поведение

- Дружба — взаимная подписка через `user_follows`; отдельная таблица друзей не создаётся.
- Общий чат доступен вошедшим активным пользователям.
- Личные сообщения можно отправлять только при взаимной подписке.
- История личной переписки остаётся доступна обоим участникам после отмены взаимной подписки, но новые сообщения блокируются политикой RLS.
- Наборы стикеров создают и публикуют только администраторы.

## Проверка перед релизом

После применения миграции проверь общий чат двумя аккаунтами, личную переписку при взаимной подписке, чтение истории после отписки и публикацию набора стикеров администратором. Сборка в этой среде не была подтверждена: установка npm-зависимостей завершилась по тайм-ауту, поэтому перед деплоем выполни `npm ci` и `npm run build` локально или в CI.
