Трапчик.мп3 — обновление

Распакуйте содержимое архива поверх папки проекта (например C:\trapchik_mp3_web_mvp), замените файлы. В терминале VS Code из папки проекта выполните:
  npx.cmd opennextjs-cloudflare build
  npx.cmd wrangler deploy

В обновлении есть «Моя волна» со случайным последовательным воспроизведением, поиск треков, открываемые альбомы с треклистом и исполнителями на каждом треке, анонсы и сниппеты будущих релизов, исправление горизонтального кадрирования аватара и обновлённые иконки.

Политика Supabase для воспроизведения превью уже применена к подключённому проекту. Не применяйте её повторно. Production-сборка проверена командой npm.cmd run build.
